# dota-overlay

Оверлей-шпаргалка по данным GSI: руны, день/ночь, сток кемпов, напоминания о закупе.
Крупный шрифт, 1-2 строки, подсказка появляется за 10-15 секунд до события и сама исчезает.

## Как запустить

```
pip install -r requirements.txt
python main.py
```

При первом запуске сам найдётся папка Dota 2 (через Steam) и создастся cfg:

```
<Steam>\steamapps\common\dota 2 beta\game\dota\cfg\gamestate_integration\gamestate_integration_overlay.cfg
```

Нужен перезапуск игры (или новая карта), чтобы Dota подхватила cfg. Если файл не создался -
укажи путь руками: переменная окружения `DOTA_DIR` или `settings.DOTA_DIR`.

Ключи запуска:

| ключ | что делает |
|---|---|
| `--cfg-only` | только создать/обновить cfg и выйти |
| `--force-cfg` | перезаписать cfg принудительно (старый уходит в `.cfg.bak`) |
| `--no-cfg` | не трогать cfg |
| `--debug` | поверх подсказок показывать часы, фазу, героя, золото |
| `--log-level debug` | подробный лог |

Проверка руками: `http://127.0.0.1:31337/` в браузере вернёт фазу, время игры и age последнего пакета.

## Требования к игре

- Окно Dota в режиме **«окно без рамки»** (Borderless Window), иначе оверлей не нужен.
- Игра должна быть запущена: GSI молчит в меню.
- GSI отдаёт только твоего героя и то, что видно - отсюда данные о покупках и кулдаунах.

## Что показывается

| Таймер | Подсказка |
|---|---|
| `timers/runes.py` | Баунти / Пауэр / Аркейн руна (совпадающие склеиваются) |
| `timers/daynight.py` | Ночь на 5:00, рассвет на 10:00 |
| `timers/camps.py` | Спавн нейтралов каждые 1:30 от начала игры |
| `timers/shopping.py` | Свиток ТП (заряды/кулдаун), курьер, варды |

## Настройка

Всё в `settings.py`: порт, окно (размер, позиция, шрифт, прозрачность), за сколько секунд
предупреждать (`LEAD_SECONDS`), дефолтные тайминги рун/ночи/кемпов, индексы способностей.

## Что проверено на живой игре

Проверено в пробе героя по `logs/gsi_last.json`:
- фаза: `map.game_state` = `DOTA_GAMERULES_STATE_GAME_IN_PROGRESS` (ключа `phase` у Dota нет)
- ночь приходит сама: `map.daytime` (по часам считаем только предупреждения заранее)
- время: `map.game_time` есть, есть запасной `map.clock_time`
- способности: `abilities.ability0..N`, кулдаун в `cooldown`, ищем по **имени** (`courier`, `teleport`)
- предметы: `items.slot*/stash*/teleport0/neutral*`, имена с префиксом `item_`, у свитка ТП
  есть `cooldown` и `charges`
- варды: `map.ward_purchase_cooldown`

## Структура

```
main.py        связывает модули
settings.py    все настройки
gsi_setup.py   поиск Dota 2 + создание cfg
server.py      приём POST от GSI -> state
state.py       последнее состояние игры + активные подсказки
overlay.py     окно без рамки, поверх всего, клики проходят в игру
timers/*.py    независимые таймеры: tick(state)
logs/          отладочный дамп GSI
```

Новый таймер = новый файл в `timers/` с функцией `tick(state)`. Больше ничего править не нужно.

## Flask вместо FastAPI

В `server.py` замени `create_app` на flask-версию (тот же контракт: POST `/` -> 200, GET `/` -> статус),
запуск - `app.run(host=..., port=...)` вместо `uvicorn`.
